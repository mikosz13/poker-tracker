# Problems and solutions

- **macOS will not open the app**: System Settings → Privacy & Security → "Open Anyway" (the app is not signed).
- **Windows SmartScreen**: "More info" → "Run anyway".
- **Where is my data?** macOS: ~/Library/Application Support/PokerTracker; Windows: %APPDATA%\PokerTracker. Back it up from Settings.
- **A tournament says the summary is missing**: download the summary from PokerCraft again; for a Day 2 GG sometimes offers it only later.
- **Numbers changed after an update**: a definition or a fix changed; the list of changes in [About](#/help/about/changes) says which.
